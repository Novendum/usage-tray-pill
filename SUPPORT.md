# Support

Use [GitHub Issues](https://github.com/Novendum/usage-tray-pill/issues) for reproducible bugs and include the UTP commit, Windows version, provider application version, expected result, and minimal reproduction steps.

Never attach cookies, tokens, credential files, `%APPDATA%\UsageTrayPill`, raw provider responses, account identifiers, or unsanitized screenshots.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) rather than a public issue.
