# Usage Tray Pill

## Platform
Windows 11 desktop utility, Windows PowerShell 5.1 and native WinForms. No web framework or added runtime dependencies.

## Purpose
Show remaining AI-provider usage at a glance while the user works, with an optional detailed overview, manual limits, and banked-reset notes. Providers are Codex, Claude, Antigravity, OpenCode Go, and Qwen Token Plan.

## Confirmed constraints
Preserve provider credential isolation, existing settings, keyboard-accessible native controls, click-only provider switching, right-click menus, background refresh, and fullscreen hiding. Unknown values must remain unknown. Interface copy is English. Provider icons come from approved existing sources.

## Current design request
The owner explicitly delegated creative direction: make the pill cleaner and more beautiful, redesign the overview creatively, and then restart UTP. Product behavior remains grounded in the repository; this request does not authorize dependencies, commits, publishing, or account changes.
